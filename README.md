# React + Server

# Dostępne Algorytmy Szyfrowania/Deszyfrowania:
-  xchacha-poly1305
-  chacha-poly1305
-  xsalsa20-poly1305
-  AES256 GCM
-  AES256 CCM
-  ARIA256 GCM
-  ARIA256 CCM
-  3DES-CBC + HMAC-SHA256
-  RSA-OAEP-2048 + AES-256-GCM
-  RSA-OAEP-3072 + AES-256-GCM

# Dostępne Algorytmy Enkodowania/Dekodowania:
- Base64
- Text2Hex
- URI

# Użyte biblioteki:
- Obsługa API (Servera): **express.js**
- Interfejs i strona: **React.js** oraz **Bootstrap**
- Biblioteki do algorytmów szyfrowania: **chacha20, salsa20**: **libsodium-wrappers**, **AES, ARIA, RSA, 3DES**: **encryption-for-node, @noble/ciphers**
